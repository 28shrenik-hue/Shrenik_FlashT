# Roadmap

## v1.0 — Tile-first release

1. Single always-on-top tile.
2. Premium swivel and glass interaction.
3. Structured in-tile lessons: Core Concept, Practical Scenario, Go Deeper, Knowledge Check, and Completion.
4. Reliable completion, XP, streak, and Excel persistence.
5. Cross-platform launcher validation.

### Remaining v1.0 work after RC7

1. User testing of every control on macOS and Windows.
2. Expand the curated content library beyond the nine flagship lessons.
3. Add a safe learning-goal prompt that selects and sequences relevant curated lessons.
4. Add a compact way to browse saved learning takeaways.
5. Final accessibility, keyboard-navigation, and reduced-motion review.
6. Build and verify the distributable Windows package.

Dashboard, journey, leaderboard, manager, social, and AI-coach concepts remain
post-v1.0 ideas. They must not change the tile-first interaction.
